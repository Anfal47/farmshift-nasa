About the Project

FarmShift is a NASA-powered crop rotation decision-support prototype that helps farmers explore suitable crop rotation strategies based on historical climate data, farm conditions, and farming priorities.

The Problem

Farmers face changing temperatures, unpredictable rainfall, limited irrigation water, and challenges in maintaining soil health. Choosing suitable crop rotations under these conditions can be difficult.

Our Solution

FarmShift combines NASA climate data with user-provided farm information to compare crop rotation strategies.

Users can:

* Select a farm location using coordinates or a map.
* Choose a year, soil type, previous crop, irrigation availability, and farming priority.
* Retrieve historical climate information from NASA POWER.
* Compare the top three ranked crop rotations.
* Explore a scenario with 40% less irrigation water.
* Understand the factors influencing the rankings.

NASA Data

NASA POWER Daily Point API

FarmShift uses historical climate information, including temperature and precipitation, for the selected location and year.

Technologies

* Python
* Streamlit
* NASA POWER API

Prototype Limitations

NASA climate data is real, but crop suitability scores are based on preliminary illustrative assumptions. The prototype is intended for exploring crop rotation strategies, not providing validated agricultural recommendations.
